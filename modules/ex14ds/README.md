# tema-yedekparca-3 · ex14ds — Galeri Masonry (Filtre + Lightbox)

## Nedir

tema-yedekparca-3 sitesinin matrix modülü. `Galeri Masonry (Filtre + Lightbox)` şablonu (section kökü,
sınıf `modulex-gm{{gmclass}}`) render sırasında sitenin sayfa akışına eklenir. Şablon içeriği
`index.html`'deki `{{...}}` soketleriyle, veri/tema değerleri `index.json`'la
beslenir.
